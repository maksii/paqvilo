## Performance investigations still open

- Lense configuration still imports the Mirage provider/parser graph synchronously. The exploratory import trace counted 218 Mirage modules. Lazy parser loading needs a separate design and configuration-compatibility regressions.
- RSA signing-key generation is already deferred until first use by `cccee94e`. The benchmark's application-free API does not measure configured secret-registration hashing; it cannot establish that that cost disappeared.
- The earlier 3–14 second browser-close observation did not reproduce in these idle paired samples. Loaded shutdown cost remains a separate investigation; lifecycle correctness is now covered by controlled fixtures.
- The first admin state body remains about 3.71 MB. Reducing it needs an explicit projection/consumer contract and completeness regressions.
- Capture still uses the bounded `networkidle` observation in `mirage/verify.mjs`. Replacing it requires capture-readiness/parity evidence rather than deleting the idle wait on timing grounds.
