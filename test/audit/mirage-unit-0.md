## Product findings ("product fix below")

- State checkpoint/digest serialization walked every row through nested generators (reset of a 4 MB state: seconds). My fix
  (rows serialized natively) was dropped on rebase in favour of the landed state-stream.mjs rewrite.
- server.mjs import read the whole ~1,400-file implementation tree serially (6.6-10.3 s per import on loaded Windows; the
  first /_sim/api/state hashed it again, 9 s). My batched-read fix was dropped on rebase in favour of the landed
  evidence.mjs concurrent walk and lazy import fingerprint.

## Hang found by the lead in cli.test.mjs

Root cause (verified on Node 24.22.1): a failing after hook skips every after hook registered after it. The fixture folder
removal ran first; when it failed (busy files of a just-killed CLI child on Windows), the fixture HTTP servers registered
later were never closed and kept the file process alive. Fixed: servers close through ownedFixture (closers always all run,
before removers), and the removal retries busy files briefly.
