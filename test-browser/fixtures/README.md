# Synthetic portal fixtures

All retained portal records and rows are invented for reusable platform regressions. No business export or customer acceptance runner is included.

- `code-site/`: minimal short-key `.powerpages-site` layout. The layout follows Microsoft's Power Pages samples; preserve its [NOTICE.md](code-site/NOTICE.md).
- `enhanced/`: invented enhanced component XML, pages, templates, snippet, setting, roles and permissions.

Tests serve these fixtures on loopback and block external traffic.
