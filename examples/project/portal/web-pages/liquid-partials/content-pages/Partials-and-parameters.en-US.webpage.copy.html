One component. Clear inputs.

A reusable web template accepts a title and a bounded count. The two previews below share the same query, card partial and component manifest.

{% include 'Liquid navigation' active:'partials' %}{{ snippets['Demo/Liquid guidance'] }}{% include 'Liquid account preview' title:'A short account preview' count:'2' %}{% include 'Liquid account preview' title:'A wider account preview' count:'4' %}

Change the call, keep the implementation

{% raw %}{% include 'Liquid account preview' title:'A short account preview' count:'2' %}{% endraw %}

The title defaults to Account preview. Count is converted to an integer and constrained to 1 through 4. Each row delegates to the plain Liquid account card partial.

The template contains a Power Pages manifest defining its maker-facing inputs. The JSON contract is the same manifest exported as a web file for reference.

Parameter contract
