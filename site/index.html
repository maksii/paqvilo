01 / LIVE PREVIEW

Lense

Keep the real Power Pages backend. Overlay your local JavaScript, CSS, assets and supported literal HTML edits in a dedicated browser.

  • Preview changes without uploading each edit
  • Inspect rendered elements and follow their sources
  • See applied patches, gaps and changes needing deployment
Explore Lense capabilities →

Liquid and Dataverse execute online. Browser actions can change live data.

02 / LOCAL DEVELOPMENT

Mirage

Run exported pages locally with supported Liquid rendering and simulated Dataverse. Work through identities, permissions and data scenarios on loopback.

  • Render templates, forms, lists and exported assets
  • Switch local personas and explore data scenarios
  • Repeat scenarios with project-owned acceptance tests
Explore Mirage capabilities →

Selected platform contracts are supported. Local success does not prove complete platform parity.
