## Related-case safeguards

- Generated model-driven maps reuse the overlay's conservative preallocation estimate:
  16 MiB per mapped asset and 64 MiB aggregate per client catalogue. Exhaustion keeps
  the source available and emits `MODEL_SOURCE_MAP_LIMIT`. Catalogue reload resets
  the cache and budget. A newline-heavy source regression verifies safe omission,
  authored-map preservation and later recovery.
- `sourceMaps: false` applies to both model-driven hosts (standalone and Power Pages),
  portal web files, nested template scripts and forms/lists through their request policy.
- Source map generation does not admit undeclared client assets, cross-origin URLs,
  mutating resource requests, fabricated ZIP file paths or untrusted extensions.
- Native modal callers validate their iframe and destination before announcing a
  fetch. Malformed/non-HTTP/cross-origin destinations and missing customized frames
  fail closed for Create, Edit/Details and lookup Create. Browser coverage checks
  that invalid Create markup produces no stale notice, open modal, page exception
  or remote request, and that missing Edit/Details frames do not throw. Stock server
  markup always supplies a local iframe; this closes the same failure signature
  when authored page scripts customize that markup.
