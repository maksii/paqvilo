# npm discovery

The [finalization ledger](discovery-finalization.md) records incorporation of the selected findings and two independent review rounds, superseding earlier candidate/backlog wording below.

Reviewed 2026-10-28 after completing the GitHub keyword pass and kudos index.
The [search index](discovery-search-index.md) records all first lists from
95 primary capability queries and 10 targeted follow-ups: **815 unique
package/version pairs**, including **57 without a declared repository** and
**10 declaring repositories outside GitHub**. Every returned name is retained;
these counts describe metadata screening, not 815 code/maintenance audits.
Missing registry repository metadata does not prove source is unavailable.

Thirteen candidates received deeper metadata/README or archive review below.
Exact-version metadata, publication history and integrity receipts stay under
ignored `.paqvilo/research/npm-reviews/`. Selected archives were fetched with
`npm pack --ignore-scripts` outside the toolkit and inspected as data, without
installing dependencies or executing package code. No package was added to
Paqvilo. Observed license statements do not qualify the package, its dependencies
or a proposed integration legally or operationally.
