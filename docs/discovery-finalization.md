Project-specific schemas, values, saved declarations and policy assertions stay project-owned. Existing platform engines and source compilers are reused; live deployment, production administration and arbitrary callback restoration were not inferred from this task.

## Review round 1: coverage and adversarial behavior

The finder lane re-read every selected-reference disposition against actual modules; the flow/data lane audited parser, generator, uniqueness and transaction contracts; the client lane audited native controls, PCF, source interpretation and asynchronous feedback. The primary agent independently examined compiled grant semantics and public helper composition. Accepted findings expanded the implementations above rather than being dismissed as optional backlog.

| Finding                                                                                                | Resolution and evidence                                                                                                                         |
| ------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Repeating resize tracking from updateView queued itself indefinitely.                                  | Tracking is idempotent; controlled observer tests bound update calls and verify disposal.                                                       |
| Empty Choice metadata reported integer/range APIs.                                                     | Source type identifies Choice even with no options; empty-set control tests preserve native types.                                              |
| Long iterative property chains bypassed expression depth limits.                                       | Actual AST height is bounded before recursive evaluation; 6,000-property repro returns the local unsupported contract.                          |
| Multiselect empty CSV members became option zero.                                                      | Strict token/shape validation preserves valid zero and rejects missing tokens; required empty values are explicit.                              |
| Offline generation/merge bypassed active alternate keys; activation and runtime comparators disagreed. | Shared configured-collation tuple semantics, atomic offline preflight, seeded activation and indexed runtime regressions.                       |
| FormXml numeric Boolean spellings could run disabled handlers.                                         | XML Schema Boolean normalization and trusted-dispatch tests cover active=0, enabled=0 and context=1.                                            |
| Editor completion could label a retained DOM node after its field identity changed.                    | Fresh semantic owner/source comparison at completion and redraw; controlled asynchronous/source-rebinding regression.                           |
| Generator date values could violate existing Dataverse range/DateOnly contracts.                       | Existing conversion range/shape enforced, including UTC boundary crossing; WDL ticks retains its separate year-one contract.                    |
| Pane navigation dropped the requested named source tab.                                                | Named tab/form/record identity reaches the pane and focuses after readiness; current/static/created contexts and pane reuse are browser-tested. |

## Review round 3: full-validation key-contract follow-up

The fresh full run passed thirteen lanes and reproduced a key/index compatibility failure in the remaining unit lane. That receipt was revoked. A further author/reviewer/finder round examined lookup, uniqueness, activation and offline merge together. [Microsoft’s Dataverse collation guidance](https://learn.microsoft.com/en-us/power-platform/admin/language-collations) describes environment-specific accent behavior and indexing; [alternate-key guidance](https://learn.microsoft.com/en-us/power-apps/developer/data-platform/define-alternate-keys-entity) establishes database-index uniqueness. Both configured CI_AI and CI_AS paths remain tested.

| Finding                                                                                                 | Resolution / retained assertion coverage                                                                                                                                                                                             |
| ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Lookup buckets/matching ignored the configured collation while uniqueness honored it.                   | Matcher, cache identity and tuple buckets share configured collation. The original bulk/case/accent/GUID/direct-edit/index assertions remain in explicit AI/AS fixtures, with repeated same-row PATCH/upsert and bounded index work. |
| Unquoted unsafe Int64 key literals lost digits through Number conversion.                               | The existing exact numeric parser preserves key digits; real loopback GET/PATCH/upsert distinguish adjacent unsafe Int64 records and keep repeated upserts idempotent.                                                               |
| Known text keys that looked like dates resolved to the wrong row.                                       | Source field kind controls matching/bucketing; two distinct nvarchar strings remain distinct. Legacy date coercion is still asserted under explicitly unknown/datetime metadata.                                                     |
| Typed equivalent date/decimal representations passed uniqueness/activation but selected the same row.   | Shared metadata-aware tuples normalize known typed values across runtime, activation, generation and merge; date-shaped text retains text comparison. Offline/seeded-index regressions prevent ambiguous admitted keys.              |
| Raw type:bigint metadata was recognized for comparisons but coerced as Int32 during missing-key upsert. | Coercion uses the same metadata alias fallback. Real handler tests cover fields/fieldMetadata, bigint/decimal/money, exact wire digits and atomic Int64 range failure.                                                               |

The relevant regression entry points are [data/index seams](../mirage/test/data-scale-seams.test.mjs), [key upserts](../mirage/test/concurrent-key-upsert.test.mjs), [numeric metadata aliases](../mirage/test/dataverse-key-numeric-alias.test.mjs), [offline key admission](../mirage/test/dataset-alternate-keys.test.mjs) and [seeded activation](../mirage/test/alternate-key-activation.test.mjs). No required lane, baseline rule or functional assertion was removed to turn validation green.

Corrections to earlier triage: native bounded CSV grid export, including permissions/paging/result limits, already exists; a second export engine was unnecessary. RetrieveAccessOrigin already explains ownership/direct/team sharing, so the added feature is model comparison rather than another access engine. Rooted JSON payload references already execute through the existing body/outputs/triggerBody/triggerOutputs/item/items APIs. Syntax/function/arity diagnostics do not infer types for uncaptured payloads. Private userquery storage is distinct from this shell’s exported savedquery catalogue: unsupported personal-view navigation is refused before a pane URL changes, and missing selected saved views are explicit. Named recipes recreate isolated components; active provider closures and in-flight jobs cannot be recovered from a source export.
