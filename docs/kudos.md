## Our validation finding

The demo CSS live-edit failure prompted our own [reload-stream reconciliation](../mirage/lib/platform.mjs),
[controlled protocol regressions](../mirage/test-browser/source-reload-stream.test.mjs)
and [bounded demo diagnostics](../test-browser/demo.test.mjs). This has no external
project attribution. It closes a reproduced missed-event gap; it does not prove
the exact timing of the original loaded-suite failure.

Further full-suite findings produced two original evidence fixes: [X-ray editor
feedback](../lense/xray-ui.mjs) now survives a same-selection evidence refresh
and rejects stale asynchronous completion, with [controlled browser ordering](../test-browser/xray-modal-hierarchy.test.mjs).
The [render sweep](../mirage/render-sweep.mjs) excludes simulator-owned injected
runtime scripts before its bounded retained HTML sample, so runtime growth cannot
hide authored content; full-response classification stays intact. [Regressions](../mirage/test/liquid-portal-parity.test.mjs)
preserve persona, row-count and state checks. Neither finding is attributed to an
external reference, and the exact original browser timeout ordering is unproven.
