# XrmToolBox store discovery

Reviewed **2026-10-28**, after the [GitHub keyword pass](discovery-search-index.md) and [npm pass](npm-discovery.md). This final round screens **50 of 50** requested plugins against actual local modules and regressions. No plugin was installed or executed, and no live organization was accessed. Useful behavior was independently implemented with invented schemas and loopback fixtures; no third-party code, assets or tests were copied.

The [finalization ledger](discovery-finalization.md) supersedes initial backlog triage and records all incorporated findings and two independent review rounds.

## Ranking and review method

The [official store](https://www.xrmtoolbox.com/plugins/?sortAttr=mctools_averagedownloadcount_sum&sort=desc) was captured at `2026-10-28T15:24:27.415Z`. Its **Total DL** control returned 503 public records (502 distinct names). We selected the first 50 by numeric cumulative downloads descending, breaking ties by name and store URL. Separate store records were retained. This defines “top” as download popularity on that date; it is not a quality or maintenance score. Versions and counts below are that snapshot.

Each actual store description and latest release notes was read, with module/test checks for applicability. Project links and public repository metadata were checked where resolvable. The generic XrmToolBox footer repository is the host source, so it was excluded as evidence of a plugin’s source. Declared and resolved links are kept separately, including redirects and missing sources. This is a functional screening with selected deeper source reviews, not an exhaustive audit of all source, CI, dependencies, security or licenses.

## Independently implemented results

- **#3 Plugin Trace Viewer:** diagnostic investigation exposed traces being rolled back with business writes. Original trace retention now preserves immutable diagnostic facts through nested and isolated business rollback, without republishing aborted rows or jobs. [Implementation](../mirage/lib/data.mjs), [regressions](../mirage/test/plugin-trace-rollback.test.mjs), [contract](../mirage/docs/dataverse-plugins.md). Native trace survival is supported by [Microsoft’s tracing documentation](https://learn.microsoft.com/en-us/power-apps/developer/data-platform/logging-tracing). The native 10 KB message policy was not changed.
- **#14 Easy Translator, with #4 ribbon context:** localization review exposed a hardcoded 1033 ribbon label preference. Imported source LCID now reaches classic ribbon parsing, Mirage catalogues and lazy Lense inspection. [Parser tests](../mirage/test/model-driven-ribbon-localization.test.mjs), [browser regression](../mirage/test-browser/model-driven-ribbon-localization.test.mjs). This does not reproduce the translator’s specific web-resource-label release fix.
- **#39 FormXml Manager / #44 Form related tools:** follow-on inspection found the same LCID omission in lazy form compilation. Inspector labels now respect the imported locale while structural names, form/field identities and control keys remain stable. [Implementation](../lense/model-driven-metadata.mjs), [regression](../test/model-driven-metadata.test.mjs).

## Integration decisions and retained leads

No integration qualified for adoption. These Windows administration tools generally overlap local capabilities or perform remote deployment/management. A recent push, popular download count, permissive API license label or familiar owner cannot establish sustained ownership, adequate tests and architectural fit. The declared Cinteros suite resolves to archived Biznamics/XrmToolBox.Plugins; suite source alone does not establish a dedicated current View Designer or DateTime Utility source. Five plugin repositories remained unresolved in this bounded pass (#4, #11, #19, #33, #47). That is not proof their source does not exist.

Previously retained leads are now incorporated through typed schema/fixture analysis, identity transport, permission comparison and source registration/event reports. Existing CSV export, recycle-bin, auto-number, caller settings and authorization APIs were verified as existing coverage. The finalization ledger records the exact per-reference boundaries.

The [kudos index](kudos.md) connects implemented ideas to reference projects; the [search index](discovery-search-index.md) preserves the earlier first-page coverage. Raw public ranking, detail and source-metadata receipts remain in ignored `.paqvilo/research/xrmtoolbox/`. No browsing identities, tokens or organization evidence are part of the published record.
