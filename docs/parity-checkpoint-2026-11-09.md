# Parity qualification checkpoint: 9 November 2026

This is an incomplete development checkpoint. It preserves runtime repairs,
recording adapters, safe evidence fixtures, original-test qualification guards
and test-kind reviews for continued work through CI and SonarQube.

The frozen inventory contains 7,108 original definition sites and 8,549 expanded
registrations across 948 files. At this checkpoint, the conservative private
ledger records:

- 33 fully qualified original definitions and 256 completely qualified expanded
  cases, including selected cases inside otherwise incomplete matrices.
- 419 assertion-level partial instances, counted separately from complete cases.
- 860 original definitions reviewed as toolkit-owned contracts or tooling;
  these receive no native parity credit.
- 104 open grouped findings. Newly captured SQL controls also expose a SELECT
  grammar gap that still needs remediation and ledger integration.

There are 8,293 expanded originals without complete native/package proof in that
accounting. This total includes local-purpose tests and must not be presented as
a count of exclusively native behavior. New tests and generated guards do not
reduce the original denominator. Eleven inherited whole-definition claims remain
withheld by independent review.

The latest query matrix has 53 of 63 cases protected. Its proof keeps original
official OData outputs, adapted official outputs, typed source-property mappings
and repeated native HTTP responses distinct. Native response messages are not
rewritten to resemble original inputs.

SQL Server captures support expression and function semantics only. They do not
establish Dataverse TDS availability, authentication, restrictions or transport
parity. The current SQL regression suite passes its existing controls, while
newly captured controls show incomplete SELECT predicate rejection and legacy
alias handling; the broader grammar repair is pending.

Other pending work includes model-driven fixture recording and reconciliation,
remaining frontend and Canvas host contexts, Code Apps backend bindings, the
bulk recorder's recovery review, and unresolved original assertion guarantees.
The three Liquid renderer-profile restoration changes remain unapplied pending
the previously requested exact approval. Temporary native resources are tracked
and reconciled privately by their owning recorder.

Raw signed-in captures, private environment identities, credentials and recording
journals stay outside this repository. Public fixtures contain only reviewed
portable facts. Local and hosted validation results must be reported for the
exact checkpoint commit; neither a checkpoint commit nor a passing local suite
establishes complete parity or a green PR.
